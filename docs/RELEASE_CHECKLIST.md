# Public release checklist

- [ ] Replace repository, paper, model, and dataset placeholder URLs.
- [ ] Confirm the code-license choice with all copyright holders.
- [ ] Confirm the base-model and adapter redistribution terms.
- [ ] Complete the dataset license and privacy review.
- [ ] Remove private paths, hostnames, keys, tokens, logs, and caches.
- [ ] Publish SHA-256 manifests for code, data, and weights.
- [ ] Upload adapter manifests and `training_audit.json` with every checkpoint.
- [ ] Test README commands in a clean Linux/CUDA environment.
- [ ] Add the final paper citation and DOI/arXiv identifier.
